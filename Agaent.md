# Agent for Backroad-app

Purpose

- Provide an overview and usage notes for a development assistant (agent) working with this React project.

Responsibilities

- Help run, build, and debug the project.
- Suggest code improvements and implement requested code changes.
- Follow repository conventions and avoid unrelated refactors.

How to use

- Ask the agent to run or modify the app, then confirm before major changes.
- For running locally:
  - Install dependencies: `npm install`
  - Start dev server: `npm run dev`

Project layout (key files)

- `index.html` — base HTML
- `src/main.jsx` — app entry
- `src/App.jsx` — main React component

Notes

- The agent will prefer minimal, focused changes and will run tests/builds when requested.
- If you need the agent to perform multi-step work, request a plan and it will create and track TODOs.
